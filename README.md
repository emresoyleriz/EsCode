# EsCode — AI Development Studio

Premium Windows AI-first development studio. **Architecture and planning phase — application is not implemented yet.**

## Approved scope
- Windows 11 x64 primary target; Windows 10 and ARM64 conditional.
- Electron + React + Monaco UI, .NET Host, authenticated Named Pipes, SQLite, isolated tool workers.
- Multi-agent workflows with approval, evidence, worktrees and safe recovery.
- Premium Apple-inspired original Windows interface, accessible primitives, Midnight Glass / Pearl Light.
- MVP: Project → Story → Plan → Edit → Test → Review → user-controlled Git.
- MVP permissions: Read-only, Ask, Supervised. Autonomous after security gates.

## Delivery plan
GitHub Issues track 18 epics / 54 stories / 270 checklist tasks. Priority: Windows sandbox, IPC, state/recovery technical spikes before autonomous execution.

See `docs/` and `.AI/` for architecture guidelines. Documentation is design-stage; no spike is claimed as executed.
